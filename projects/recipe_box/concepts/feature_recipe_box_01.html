feature_recipe_box_01 · implementation concept

PDF export

People print a recipe collection, or a saved selection of it, as a PDF that is easy to cook from.

User flow

  1. A person runs Export-RecipePdf -Collection "weeknight dinners" -Path dinners.pdf in a PowerShell session, and adds -Selection winter to print only part of the collection.
  2. The command writes one PDF with one page per recipe and returns its path. Messages appear in German or English, following the language of the session.
  3. The person opens the PDF and prints it, or hands it to someone who does not use recipe_box.

Design and mockups

Architecture

Export-RecipePdf is the only command people call. It resolves a saved selection, turns each recipe's fields into plain text, lays out one HTML page per recipe and lets the print engine of the operating system write the PDF, so the layout lives in one HTML template. Messages come from resources/<lang>/strings.psd1. Recipes are read and written on the same computer; nothing is uploaded.

Test approach

  • Integration for req_recipe_box_0001: export a made-up collection of 1,000 recipes, then count the pages and open the PDF without a repair prompt.
  • Unit for req_recipe_box_0003: Pester tests of ConvertTo-RecipeText and Get-SafeUrl with amounts, units, links of every scheme and notes.
  • Each test carries the requirement ID in its Describe name, so the JUnit XML report of the CI run links it back.

Export a collection as PDF
The module shall export all recipes of a collection to a PDF file, one page per recipe.		spec_recipe_box_0001 version 1
PDF export pipeline
Export-RecipePdf reads the recipes of a collection, resolves a saved selection with Resolve-RecipeSelection, renders one HTML page per recipe with ConvertTo-RecipePrintHtml and prints the result to PDF. Messages come from resources/<lang>/strings.psd1.
req_recipe_box_0003 version 2
Readable ingredient lists
The PDF shall show amounts, units, links and notes as readable text.		spec_recipe_box_0002 version 2
Ingredient text conversion
ConvertTo-RecipeText turns amounts, units, links and notes into plain text for the PDF. Get-SafeUrl lets only http and https links through; any other link is printed as text.
